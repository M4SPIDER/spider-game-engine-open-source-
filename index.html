Model Context Protocol (MCP)

How Autonomous 3D Creation Works

Spider Engine doesn't just guess code. It embeds a local MCP server on port 9287 that gives LLMs eyes and hands on the 3D canvas:

  • 1
    Tool: check3DView — Inspects compilation errors, actor trees, and 60 FPS animation loop health.
  • 2
    Tool: captureScreenshot — Takes instant 512px WebGL base64 snapshots so models can see visual bugs like Z-fighting.
  • 3
    Tool: render_jsx — Hot-mounts new React Three Fiber modules directly with instant AST compilation caching.

⚡ Next-Gen Engine Capabilities

Engine Systems & Developer Tools

Built from the ground up for high-speed game prototyping, autonomous AI agent execution, and studio-grade 3D performance.

Meta Muse Real-Time Speech (3.1% WER)

Ultra-low latency (~0.16s) live speech recognition streaming over WebSockets (wss://api.meta.ai/v1/asr/realtime) with native turn endpointing. Words stream into the prompt box as you talk.

Blender Real-Time MCP Bridge

Bi-directional TCP socket bridge on port 9876 connecting Spider Engine directly to Blender for instantaneous 3D geometry, transform, lighting, and camera synchronization.

Spider Slash Commands

Instant command palette (/blender, /plan, /play, /browser, /clear, /stop, /help) with keyboard arrow navigation and tab autocomplete.

Multi-Platform Desktop & Web

Runs as a high-performance Electron desktop app, ultra-lightweight Rust Tauri binary, or standard Vite web server. Universal mobile and tablet support with zero setup.

Tournament Studio Lighting

Dual key and fill shadow-casting lights, soft ambient hemisphere light, and logarithmic depth buffer eliminate all visual artifacts and Z-fighting.

Dual Governance & DPAPI Security

Toggle between Ask Permission (Secure Mode) for interactive approval and Auto Mode for autonomous execution with OS-level DPAPI keychain protection.

🏛️ Technical Blueprint

7 Core Engine Architectures

Comprehensive subsystem workflows designed for modularity, low-latency execution, and autonomous agent verification.

1 High-Level Cross-Platform Runtime

Decoupled presentation layer with React 19 UI shell, Three.js canvas, and platform adapters for Electron (Node.js IPC), Tauri (Rust), and WebGL.

2 Meta Muse Real-Time Voice ASR

16 kHz mono Int16 PCM streaming pipeline delivering cumulative partial transcripts with 3.1% WER and ~0.16s latency via WebSockets.

3 Autonomous Agent MCP Server (:9287)

Embedded Model Context Protocol endpoint supporting listScene, render_jsx, moveObject, check3DView, and screenshot vision loops.

4 Dynamic JSX AST Hot-Mount Compiler

Babel standalone transpiler with in-memory multi-file virtual module resolver, hot-mounting R3F components without browser reloads.

5 Blender Real-Time MCP Bridge (:9876)

Bi-directional TCP socket bridge enabling live asset interchange, shader synchronization, and spatial lighting previews with Blender.

6 Multi-Tier State & DPAPI Storage

Four-tiered storage architecture: Volatile RAM Refs, Encrypted LocalStorage via Windows DPAPI, IndexedDB scene trees, and native disk I/O.

7 3D Game Viewport & Physics Simulation Engine Pipeline

Continuous 60 FPS useFrame simulation loop with delta-time normalization, raycasting collision solver, ACESFilmic tone mapping, and logarithmic depth buffer.
