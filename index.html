How Autonomous 3D Creation Works

Spider Engine doesn't just guess code. It embeds a local MCP server on port 9287 that gives LLMs eyes and hands on the 3D canvas:

  • 1
    Tool: check3DView — Inspects compilation errors, actor trees, and 60 FPS animation health.
  • 2
    Tool: captureScreenshot — Takes instant 512px WebGL base64 snapshots so models can see visual bugs like Z-fighting.
  • 3
    Tool: render_jsx — Hot-mounts new React Three Fiber modules directly with instant AST compilation caching.
