How Autonomous 3D Creation Works

Spider Engine doesn't just guess code. It embeds a local MCP server on port 9287 that gives LLMs eyes and hands on the 3D canvas:

  • 1
    Tool: check3DView — Inspects compilation errors, actor trees, and 60 FPS animation loop health.
  • 2
    Tool: captureScreenshot — Takes instant 512px WebGL base64 snapshots so models can see visual bugs like Z-fighting.
  • 3
    Tool: render_jsx — Hot-mounts new React Three Fiber modules directly with instant AST compilation caching.

Complete Developer Autonomy & Host Integration

Full CLI Commands, System-Wide Files
& Dual Permission Modes

Spider Engine empowers AI agents with complete host operating system capabilities. On desktop, the agent can execute real terminal commands, create multi-file architectures anywhere on your machine, and run in either strict Ask Permission mode or zero-friction Auto Mode — and you can even chat with it live while it's working without stopping streaming!

🌐 Browser Mode & Execution Limits: Same 3D Game, Universal Access

In pure web browsers (Chrome, Safari, Firefox, Edge, iOS & Android), host OS CLI commands cannot be run directly due to browser security sandbox constraints. However, the AI agent still works within browser limits and creates the exact same 3D games and simulations! It compiles React Three Fiber JSX in-memory, resolves modular file imports live, and persists your full scene state and source code to IndexedDB and localStorage so nothing is ever lost on refresh!

Real CLI Execution runCommand

In desktop mode, the agent runs real shell commands natively on the host machine using powershell.exe on Windows and /bin/bash on Linux/Unix systems.

  • Live streaming stdout/stderr directly into terminal
  • Runs package managers: npm install, cargo build, tsc
  • Git workflows, standalone exe compiles & diagnostic tools
$ spider.runCommand("cargo build") [Live]

Create Files Anywhere fs.write

System-wide file creation and modification capabilities across the entire computer. The agent automatically creates nested directories and scaffolds full project folders.

  • Deep filesystem access: read, write, edit, and organize
  • Scaffolds multi-folder game components, audio & 3D assets
  • Real-time folder watching with live hot-reloading in 3D
$ spider.writeFile("src/game/Arena.jsx") [Disk OK]

Permission vs Auto Mode Dual Mode

Stay in complete command. Toggle between interactive safety approval and full autonomous velocity with 1 click:

  • Ask Permission (Secure Mode): Prompts with an approval card before running CLI commands or writing files.
  • Auto Mode (No Permission): 100% autonomous speed. Executes commands and builds without stopping.
  • Chat While Streaming: Send new ideas or corrections while the agent is running without interrupting streaming!

Source/YourProject/SpiderGameActor.cpp 
// Unreal Engine 5 Actor Implementation (transpiled from Spider Engine)
#include "SpiderGameActor.h"

ASpiderGameActor::ASpiderGameActor() {
    PrimaryActorTick.bCanEverTick = true;
    HeroMesh = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("HeroMesh"));
    RootComponent = HeroMesh;
}

void ASpiderGameActor::BeginPlay() {
    Super::BeginPlay();
    Score = 0;
}

void ASpiderGameActor::Tick(float DeltaTime) {
    Super::Tick(DeltaTime);
    // 1:1 match with Spider Engine's exported Update(dt) loop:
    FVector Pos = GetActorLocation();
    Pos.X += MoveInput.X * MoveSpeed * DeltaTime;
    Pos.Y += MoveInput.Y * MoveSpeed * DeltaTime;
    SetActorLocation(Pos);
}
